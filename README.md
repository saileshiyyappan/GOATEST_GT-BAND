## Overview

**GT-Band** is a modular wearable health technology platform developed under GOATEST. It combines embedded electronics, physiological and environmental sensing, motion monitoring, and wireless connectivity in a wearable hardware system.

The platform is designed to support personalized health monitoring, distributed sensing, and integration with a companion application.

## Key Features

- Modular wearable hardware architecture
- Physiological, environmental, and motion sensing
- Embedded processing using ESP32-based hardware
- Wireless communication with compatible system components
- Expandable hardware and sensor integration
- Companion application connectivity
- Research-oriented emergency-support capabilities

## Hardware Components

| Component | Purpose |
|---|---|
| ESP32 | Embedded processing and connectivity |
| MAX30102 | Optical pulse and oxygen-saturation estimation |
| AD8232 | ECG signal acquisition |
| MPU6050 | Motion and acceleration sensing |
| BMP180 | Atmospheric pressure measurement and altitude estimation |
| DHT11 | Temperature and humidity sensing |
| GPS module | Location information |
| GSM module | Cellular communication support |
| OLED display | Local information display |
| MicroSD module | Local data-storage support |

*The table summarizes components used or planned within the prototype ecosystem; the final configuration may vary by hardware revision.*

## System Architecture

GT-Band uses a modular hardware approach to support sensing, local processing, and communication with connected software.

- **Wearable sensing:** Acquires physiological, environmental, and motion-related signals.
- **Embedded control:** Coordinates connected hardware and sensor interfaces.
- **Wireless connectivity:** Supports communication between compatible system components.
- **Application integration:** Provides a path for viewing and managing collected information.

Detailed circuit designs, proprietary processing methods, and implementation-specific architecture are intentionally excluded from this public overview.

## Development Status

GT-Band is an ongoing engineering and research project with a working hardware prototype. Development focuses on hardware integration, wearable design refinement, sensor evaluation, firmware integration, and further system validation.

The prototype is not presented as a clinically validated or certified medical device.
